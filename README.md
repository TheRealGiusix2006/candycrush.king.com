#  Candy Crush Saga - Flash Version
This project restores the classic **Candy Crush Saga** game that originally ran on Facebook and king.com. It recreates api responses through **FPMockRequest.js**. Social apis are **not** recreated, as the game is intended to work offline.

##  Features

- Local handling of the apis in JavaScript.
- Runs locally, without internet!

##  Requirements

- [XAMPP](https://www.apachefriends.org/)
- Flash Player and WaterFox Classic, Basilik or any other browser that supports Flash.
- A copy of the repository (available in releases or code).

1) Rename one file the FPMockRequest.js files. _language_level0 file starts you at level 1 and the _FULL one is fully complete.
2) Drag the contents of this repository into htdocs (usually at C:/xampp/htdocs, DO NOT MAKE A SUBFOLDER) and start Apache in xampp-control.

You can now play the game [here](http://localhost/) and enjoy!
