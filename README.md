#  Candy Crush Saga - Flash Version
This project restores the classic **Candy Crush Saga** game that originally ran on Facebook and king.com. It simulates api responses through **FPMockRequest.js**.

##  Features


- Local handling of the apis in JavaScript.
- Runs locally, without internet!

##  Requirements

- [XAMPP](https://www.apachefriends.org/)
- Flash Player and WaterFox Classic, Basilik or any other browser that supports Flash.
- A copy of the repository (available in releases or code).

Simply drag the contents of this repository into htdocs (usually at C:/xampp) and start Apache in xampp-control.

You can now play the game [here](http://localhost/candycrush) and enjoy!
